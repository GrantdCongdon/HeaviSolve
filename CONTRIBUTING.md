# Contributing

Use `git commit -s` to certify the [Developer Certificate of Origin 1.1](https://developercertificate.org/). No CLA or copyright assignment is required. Never sign for another contributor.

Each source/configuration file needs SPDX copyright and AGPL-3.0-or-later headers; prose uses CC-BY-SA-4.0. Preserve upstream licenses verbatim with REUSE sidecars where appropriate. Dependency additions need ADR-002 review and an inventory entry before merge. Do not commit PDKs that require registration or NDA.

Run foundation checks and REUSE lint before committing. A green foundation build does not close M0. Numerical outputs must be generated by tests and retained in CI.
