# Primary references

Source/date/license details are maintained in the [solver survey](research/solver-survey.md), [PDK survey](research/pdk-survey.md), and [SPICE comparison](research/spice-engine-comparison.md).

- [MFEM examples and formulations](https://mfem.org/examples/): Poisson and Maxwell benchmark foundations.
- [MFEM v4.8 source](https://github.com/mfem/mfem/tree/v4.8): pinned local numerical dependency.
- [Palace documentation](https://awslabs.github.io/palace/stable/): EM workflows, modal boundaries and circuit quantization.
- [Gmsh manual](https://gmsh.info/doc/texinfo/): native API and mesh-quality definitions.
- [ngspice shared library](https://ngspice.sourceforge.io/shared.html): embedding callbacks and vector lifetimes.
- [IHP process documentation](https://ihp-open-pdk-docs.readthedocs.io/en/latest/): public process/model workflows; individual files retain their licenses.

The director's full textbook/paper bibliography will be expanded with verified editions and identifiers as corresponding features are implemented. No textbook content or proprietary simulator data is redistributed.
